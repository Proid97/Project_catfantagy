# 운빨냥국배틀

주사위로 자원을 얻고, 카드로 고양이 병사와 건물을 배치하는 턴제 판타지 영토 게임입니다. 이름은 가칭입니다.

안개 속 시작 위치, 자원을 주는 숫자, 뽑히는 카드가 매 판을 바꿉니다. 얻은 운을 바탕으로 냥국을 넓히고 상대 왕성을 공략합니다.
